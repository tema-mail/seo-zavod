Коротко

Что строим. «Завод AI сфера» – веб-приложение на нашем сервере в Нидерландах. На Мак ставится как приложение, так же как наши «Встречи»: иконка в Dock, своё окно без адресной строки, вход по паролю. Внутри SEO-завод: спрос, карта страниц, статьи блога, проверка, выкладка по расписанию, обходчик, сторож страниц, сеть площадок (ВК, Дзен, Телетайп, Яндекс и Google Карты) и замер, называют ли нас нейросети. Прогноз – ~200–280 часов до рабочей версии для студии (этапы 0–5), продажа – отдельный этап ~100–140 часов, когда до неё дойдём.

Где что работает. Всё на сервере NL круглые сутки. Компьютер – только окно: закрыл ноутбук – завод пишет и выкладывает дальше.

Для кого. Сейчас только для студии, в приложении один человек – владелец. Ничего не зашиваем под нас (ни сервера, ни ключей, ни путей), чтобы потом продать.

Путь владельца: от входа до работы

  1. Открыл адрес и вошёл. Адрес завода (поддомен студии, вопрос 18), логин и пароль. Весь кабинет за входом, двухфакторный вход – по желанию.
  2. Поставил как приложение. В Chrome – кнопка «Установить», в Safari – «Файл → Добавить в Dock». Дальше завод открывается своим окном из Dock, как «Встречи».
  3. Подключения. Claude по подписке – долгий токен setup-token для завода на сервере (отдельный от бота Евы). Вебмастер и Метрика – токен Яндекса, Search Console – сервисный ключ, XMLRiver с потолком денег, ключ ВК, Telegram для уведомлений. У каждого кнопка «Проверить» – живой запрос с кодом ответа.
  4. Сайт. EV Sibir: адрес, репозиторий, регион, куда класть статьи, команда выкладки (у EV – scripts/deploy.py), расписание и переключатель «без одобрения не выкладывать».
  5. Знакомство. Завод собирает факты о компании и красный список сайта по брифу, владелец подтверждает. Дальше станции идут сами, а приложение показывает, где нужно «да».
Клиентский путь (свой сервер, мастер установки, вход в нейросети у клиента) – к этапу продажи, по образцу черновика 5.

Обновление страниц: сигналы и правила

Обновляем не по календарю, а по сигналам сторожа (Google и Яндекс частоту не задают; агентства тоже сходятся на «по сигналам»). Сеть площадок и ИИ-видимость

Зачем. Нейросети отвечают не только по сайтам. В Новосибирске Алиса строит ответ про услуги из карточек на картах и площадок: в срезе 06–07.11.2026 во всех 6 ответах Яндекса по услугам TEYES стоят 2ГИС, Zoon, Авито и сервисы Яндекса; среди источников Алисы в Вебмастере TEYES есть Дзен. Значит, завод выводит компанию не только в поиск, но и туда, откуда нейросети берут ответы. У Васина этого нет – это наш шаг дальше.

Как устроено

Одна тема → сначала страница сайта (первоисточник, всё важное лежит там) → по ней свой текст для каждой площадки, где у темы есть своя польза. Не копия: Дзен раскрывает глубже, ВК – короткая узнаваемая ситуация, Телетайп – библиотека для ссылок из переписки, карты – только настоящее событие (работа, акция, изменение).

Разъём площадки. Каждая площадка – модуль с пятью действиями: подготовить (текст, обложка, ссылка с UTM), проверить (общие гейты + правила площадки в красном списке), выложить (API, RSS или полуручной путь), проверить выход (открывается, нет noindex, ссылка живая), снять цифры. Новая площадка – новый модуль без правки ядра: следующими в очереди стоят drive2, auto.ru, 2ГИС, Telegram, vc.ru (агенты drive2 и autoru у студии уже есть).

Главное по выкладке (проверено 15.11.2026): сам завод выкладывает только на сайт и в Дзен через RSS сайта. ВК, Телетайп, Яндекс Бизнес, Google Карты, auto.ru, drive2 – готовый пакет, публикует человек. Порядок вложений для поиска и ответов нейросетей: карточки Яндекс Бизнеса и 2ГИС → сайт в топе → соцсети как поддержка.

Полуручной путь – там, где у площадки нет API. Кнопка «Выложить» в приложении открывает кабинет площадки, кладёт текст в буфер и картинки папкой; человек жмёт «опубликовать» и вставляет ссылку; завод сам проверяет выход и дальше снимает цифры. Пароли от площадок в завод не передаём.

Станция 13: ИИ-видимость

Раз в месяц, только после «да» на конкретный сайт и с ценой среза заранее (правило студии: съём нейросетей стоит денег). Источники: обзоры Google и ответ Яндекса с источниками по городу через XMLRiver (25 ₽ за 1 000 запросов), «Видимость сайта в Алисе» из Вебмастера (только кабинет, без региона); ChatGPT и Perplexity – по ключу, по желанию. Метод: каждая нейросеть отдельно, запросы без нашего бренда, повторы, контрольная группа. Итог – доля ответов, где нас называют, и список площадок, которые цитируют вместо нас. Из этого советник ставит задачи: какую карточку поправить, на какую площадку выйти. Что размещение на площадке поднимает упоминания в ответах ИИ, не доказано ни у кого – это замер, клиенту не обещание.

Безопасность

  • Песочница агентов. Claude и Codex читают чужие страницы (конкуренты из выдачи), а в странице может быть внедрённая команда. Поэтому: движок и агенты работают под разными непривилегированными пользователями; файлы секретов агенту не читаются; на станциях с веб-данными агенту разрешено только чтение – без запуска команд и без сети, кроме выдачи из кэша; «Задание заводу словами» работает в копии папки сайта, итог – только черновик; выкладку, git и платные запросы делает код движка после гейтов, а не агент.
  • Движок слушает только 127.0.0.1, наружу – только Caddy на 443 с Let's Encrypt. Весь кабинет за входом: без сессии любой адрес отдаёт 401. Пароль – хэш (argon2), после 5 неверных попыток – пауза; двухфакторный вход по желанию.
  • Сессия – cookie HttpOnly, Secure, SameSite=Strict; выход везде – кнопкой.
  • Токены и ключи – на сервере, права 600. В окно и в журнал не попадают; в логах – маска.
  • Сервер общий с ботом Евы и автостатьями: у завода свой пользователь, своя папка и свой токен Claude, чужие файлы ему не читаются.
  • Потолки денег держит движок: задача дороже потолка ждёт «да». Порог «без вопроса» задаётся в профиле сайта (у студии – XMLRiver до 150 ₽ на задачу).
  • Каждое внешнее действие (выкладка, переобход, платный запрос) – в журнале: кто, когда, чем.
  • Копия базы и данных сайта – каждый день, не на этом же сервере: в хранилище S3, которое указал владелец (для проектов РФ – Cloud.ru). «Доктор» раз в неделю пробно восстанавливает копию во временную папку.
  • Перед продажей – проверка скиллом «безопасность».

Обновление движка

  1. У студии. Новая версия – коммит в закрытом репо → скрипт выкладки на сервер NL: остановить приём новых задач, дождаться текущих (до 30 минут), копия базы, миграции, перезапуск, «Доктор». Не прошёл за 10 минут – откат на прошлую версию и копию базы.
  2. Окно обновляется само: при новой версии движка страница перезагружается.
  3. Claude Code – версия закреплена, самообновление выключено (DISABLE_AUTOUPDATER); новая версия CLI – только вместе с проверенной версией движка.
  4. У клиентов (к продаже) – подписанные архивы волнами 10 % → все, как в черновике 5.

Два уровня. «Я живой» и проверка лицензии – обязательны для всех: без них нет обновлений и поддержки. Суточная сводка – по согласию; без согласия клиент виден во «Флоте» серым: только жив / не жив, версия и шаг установки.

Правила разработки для программистов

  • Новый закрытый репозиторий под код; git до первой строки кода. Коммит после каждого проверенного шага, описание по-русски.
  • Файл кода – до 800 строк; шаг – до 3 файлов кода вместе с тестами и настройками.
  • Каждый гейт и каждое правило конвейера – с тестом. Перед коммитом set -o pipefail.
  • В коде нет адресов наших серверов, путей мака, ключей, имён клиентов – только настройки.
  • Тексты интерфейса: короткое тире «–», без иероглифов; кнопка называет, что человек получит.
  • Правила студии (порог XMLRiver 150 ₽ без вопроса, часовой пояс МСК, «длинное тире – стоп», набор гейтов) – это профиль «Студия» в настройках сайта, а не код. У клиента свой профиль со своими значениями.
  • Перед выкладкой в main – скилл deploy-check; существенная правка – независимый change-reviewer.
  • Старый код студии (seozavod, avtostati, админка TEYES, РУКИ) не трогать; брать из него только логику как образец. Сторож (seo-lead/scripts/storozh.py) и красный список (znaniya/krasnyy-spisok) – готовые куски, переносим в движок.
  • Интерфейс – по макету ../interfeys/; веб-приложение по образцу «Встреч» (манифест, иконка, установка).
